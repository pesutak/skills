Vertical Codebase

From scattered to structured

Audit, plan, and transform codebases from horizontal to vertical architecture. Based on The Vertical Codebase by TkDodo.

Audit

/vertical-audit

Deep analysis of your codebase structure. Detects horizontal patterns, scattered domain code, missing boundaries. Scores 1-10.

scandetectscorepropose

Plan

/vertical-plan

Generate a detailed transformation plan with file moves, import updates, barrel files, and safe execution order.

file movesimportsbarrel files

Refactor

/vertical-refactor

Execute the transformation safely. Moves files with git mv, updates imports, creates barrels. One vertical at a time.

git mvsafeincremental

Check

/vertical-check

Validate boundaries post-refactor. Detect import violations, score vertical health, suggest ESLint enforcement rules.

validatehealth scoreeslint
The problem

Horizontal vs. Vertical

Stop grouping code by what it is. Start grouping by what it does.

Horizontal (type-based) 
src/
  components/  200+ unrelated files
    ProfileCard.tsx
    ProfileAvatar.tsx
    DashboardWidget.tsx
    DashboardChart.tsx
    ...
  hooks/
    useProfile.ts
    useDashboard.ts
    ...
  utils/       grab-bag
    profileHelpers.ts
    dashboardFormat.ts
    ...
  types/
    profile.ts
    dashboard.ts
Vertical (domain-based) 
src/
  profile/         all profile code
    ProfileCard.tsx
    ProfileAvatar.tsx
    useProfile.ts
    helpers.ts
    types.ts
    index.ts       public API
  dashboard/       all dashboard code
    DashboardWidget.tsx
    DashboardChart.tsx
    useDashboard.ts
    format.ts
    index.ts
  design-system/   shared UI

Recommended workflow

/vertical-audit
→
/vertical-plan
→
/vertical-refactor
→
/vertical-check
