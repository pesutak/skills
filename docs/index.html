How it works

Plain markdown, zero magic

No databases, no special formats. Just markdown files with YAML frontmatter in a structured directory.

1

Initialize

Run /notes-init to create the .notes/ directory in your project

2

Create

Use /note, /task, /kb, or /hint to add entries

3

Tag

Entries are tagged for cross-cutting organization and fast discovery

4

Search

Use /notes-search to find anything by content, tags, type, or project

Get started

Install in 30 seconds

Copy the skill files to your project and start managing your knowledge.

terminal 
# From your target project directory
mkdir -p .claude/skills

# Copy skills
cp /path/to/skills/notes-management/skills/*.md .claude/skills/

# Copy conventions
cp /path/to/skills/notes-management/CLAUDE.md .claude/notes-system.md
terminal 
# Symlink the skills directory
ln -s ~/skills/notes-management/skills/ .claude/skills/notes-management
terminal 
# Clone the skills repo
git clone https://github.com/pesutak/skills.git ~/skills

# Symlink into your project
ln -s ~/skills/notes-management/skills/ .claude/skills/notes-management
